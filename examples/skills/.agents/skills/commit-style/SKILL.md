# Commit style

1. Start with a type and scope, like `feat(skills): ...` or `fix(hooks): ...`.
2. Describe the change in lowercase after the colon, with no trailing period.
3. The message body explains why the change was made, not what the diff shows.
4. Keep the subject line to 72 characters or fewer.
